# 📚 Fundamentos de Kotlin

Repositório dedicado aos meus estudos e à evolução na linguagem **Kotlin**, cobrindo desde a base da sintaxe até conceitos avançados de programação orientada a objetos e lógica.

---

## 🚀 Sobre o Repositório
Aqui centralizo os códigos, exercícios e exemplos desenvolvidos nas aulas da faculdade, com o objetivo de fixar a teoria através da prática.

## 📂 Estrutura
O projeto está organizado e dividido por aulas para facilitar a revisão dos conteúdos e acompanhamento dos estudos.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Kotlin
* **Ambiente de Desenvolvimento:** IntelliJ IDEA / VS Code
* **Controle de Versão:** Git e GitHub
